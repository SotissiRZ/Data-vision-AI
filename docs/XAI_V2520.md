# DataVision AI v2.52.0 — Explainable AI

v2.52 consolide l'explicabilité comme une couche analytique gouvernée et reproductible.

## Principes

- aucun LLM n'effectue les calculs XAI ;
- chaque explication est reliée au modèle sauvegardé et au dataset de référence ;
- les sorties XAI décrivent le comportement du modèle et ne sont jamais présentées comme causales ;
- le holdout final reste le référentiel des diagnostics lorsque ses indices sont disponibles ;
- les contre-factuels doivent respecter les contraintes d'actionnabilité définies par l'utilisateur ou le métier.

## Capacités

- permutation importance avec moyenne, dispersion, stabilité et cohérence de signe ;
- matrice de confusion, précision/rappel/F1/support par classe ;
- calibration par classe, Brier et ECE ;
- SHAP global/local avec garde de coût et fallback explicite ;
- dépendance partielle numérique et catégorielle ;
- explication locale par perturbation ;
- contre-factuels bornés avec variables immuables/actionnables et contraintes min/max/valeurs autorisées ;
- audit XAI unifié avec `explanation_id`, SHA-256 du modèle et du dataset de référence ;
- résumé de l'audit persisté dans la Model Card et repris par les blocs modèle du Report Builder.

## API

- `GET /api/v1/datasets/models/{model_id}/diagnostics`

- `GET /api/v1/datasets/models/{model_id}/xai/capabilities`
