# Historique documentaire

Ce dossier contient les artefacts historiques conservés pour audit et traçabilité.

- `validations/` : validations versionnées des anciennes releases.
- `migrations/` : guides et notes de migration historiques.
- `manifests/` : manifests historiques déplacés depuis d’anciennes racines de dépôt.

Les anciennes versions des documents racine sont également conservées ici lorsque nécessaire.

La documentation normative actuelle se trouve dans `docs/README.md`.
